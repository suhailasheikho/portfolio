# Suhaila Sheikh Portfolio

A responsive HTML/CSS/JavaScript portfolio recreated from the supplied design reference.

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Customize
- `assets/devora-logo.png` is the supplied Devora logo used in the Hero and About sections.
- Edit text, project names, links and contact details in `index.html`.
- Adjust colors/layout in `css/style.css`.
- Connect the contact form in `js/script.js` to Formspree, EmailJS, PHP, Node.js, or your own API.

No build step or framework is required.
